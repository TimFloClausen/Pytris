# Tetris Built with Python and Pygame

My second game built with Python — a simple Tetris game that I am developing from scratch.

## About

The goal of this project is to create a simple and playable version of **Tetris** using Python and Pygame.

The game will be based on the classic Tetris gameplay, where falling blocks have to be moved and rotated to create complete rows.

The game will include features such as:

- Falling blocks
- Moving blocks left and right
- Rotating blocks
- Clearing completed rows
- Score system
- Increasing difficulty

More features may be added later during development.

## Goal

The main goal is to build my first game with Python and **Pygame** while learning how game development works.

I want to learn how to handle things such as:

- Game loops
- Keyboard input
- Game objects
- Collision detection
- Graphics and rendering
- Game logic

## Status

The game is still in an early stage of development. More features and improvements will be added over time.
